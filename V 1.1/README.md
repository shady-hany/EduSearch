# EduSearch

Information Storage and Retrieval · Education (Domain 03) · Fall 2026

A small exact-phrase search engine for the assigned ten education documents. The interface is a static website; ranking is calculated in the browser from the exported positional index and document vectors. No API, database, external fonts or JavaScript framework is needed.

## Publish on GitHub Pages

1. Extract the project ZIP. Create a public repository named `edusearch` (or any name).
2. Upload **the contents** of the extracted project to the repository root, not the containing folder. Include hidden `.nojekyll`, `.gitignore` and `.github` if possible. Git is recommended to preserve them.
3. Commit to `main`. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Open the URL shown in Pages after deployment. It will normally be `https://YOUR-USERNAME.github.io/edusearch/`. The actual URL depends on your account and repository name.

All site links and data paths are relative, including when hosted under a repository subpath. The website is already built and does not need Python installed on GitHub Pages. Do not upload the team roster or other students' personal data. This project contains only the assigned Education dataset.

### Preview locally

From the project root:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/`. Do not double-click `index.html`: browsers may block module and JSON loading on `file://` URLs.

## Academic Spark build (required for Part A)

Use Python 3.10+ and Java 17 or 21. Install dependencies in a virtual environment, then run the default Spark build:

```sh
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python src/build.py --engine spark
python -m unittest discover -s tests -v
node --test tests/engine.test.mjs
```

`src/build.py` uses PySpark DataFrames: lowercase → split → posexplode → 1-based position → group by term/document → sorted positions. The resulting index is passed into the Python retrieval pipeline (Part B), which exports the website model and all CSV/JSON tables. The code also checks the Spark index against an independent Python implementation before exporting. If Spark fails to start because of hostname resolution, try setting `SPARK_LOCAL_IP=127.0.0.1` in your shell. Java must be available on PATH or JAVA_HOME.

The included `data/model.json` and `outputs/` were generated by the independent Python fallback (`python src/build.py --engine python`), because PySpark could not be installed in the authoring environment. **Run the Spark command before submitting Part A**; it regenerates the same outputs with Spark provenance. Commit the regenerated files if desired. The GitHub Actions workflow also installs Java/PySpark, runs the Spark build, then runs both test suites; it is supplied but has not been executed on your GitHub account. A passing workflow does not automatically commit generated files.

### Google Colab alternative

## Usage

- **Search:** enter a single word/phrase or two phrases joined by `AND` or `AND NOT`. Examples are selectable. Matches are exact contiguous tokens; search is case-insensitive. Boolean words are reserved syntax. OR and nested expressions are outside the assignment scope.
- **Documents:** original text, token counts, numbered tokens.
- **Positional index:** filter terms and inspect all postings; export CSV.
- **Term statistics:** raw TF, weighted TF, DF and IDF.
- **Vector space:** TF-IDF, document lengths, normalized TF-IDF.
- **Validation:** live comparison of all four assigned query rankings against the reference.
- **Methodology:** implementation rules, formulas and deployment architecture.

## Reference results

| Query | Ranked documents with cosine similarity |
| --- | --- |
| online learning | d1 (1.0000), d5 (0.4476), d2 (0.4226), d9 (0.1939) |
| student assessment | d3 (0.4226), d5 (0.3051), d8 (0.2731) |
| online learning AND student assessment | d5 (0.5322) |
| online learning AND NOT student assessment | d1 (1.0000), d2 (0.4226), d9 (0.1939) |

All 28 positional index entries, all four 28×10 matrices, DF/IDF, vector lengths, required phrase positions and the four rankings are tested against the supplied Education reference (pp. 16–20). Floating-point calculations retain full precision; presentation rounds to four or six decimal places. Python and Node tests passed in the authoring environment. Browser end-to-end execution was blocked by the environment's browser URL policy, so visual and deployed-browser testing remain to be done on your device. The site uses standard static HTML, CSS and JavaScript.
